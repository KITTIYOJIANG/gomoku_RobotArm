# J1 五子棋机械臂精简版 GUI 使用说明

## 1. 软件用途与控制边界

本软件是在原 J1 五子棋机械臂软件上精简得到的标定优先界面，保留：

- 摄像头与棋盘定位；
- COM 下位机连接；
- QUICK 5 / STANDARD 9 快速标定；
- 15×15 点位验证；
- 回观察位、取料、固定点演示；
- 气泵关闭、急停和日志。

界面没有 DRY RUN 开关。只有显式连接 COM 后，已启用的动作按钮才会向下位机发送命令。软件启动时不会自动连接摄像头、不会自动连接 COM，也不会自动运动。

> 机械臂没有可靠的通用“已到位”反馈，软件根据动作时间估计完成。物理断电仍是最终安全手段。

## 2. 启动前检查

每次连接下位机前必须确认：

1. 机械臂工作区、取料区和棋盘上方没有人员、工具或线缆。
2. 机械臂已可靠安装；必要时使用支撑，避免突然下坠。
3. 已准备物理断电手段，并且操作者能够立即触及。
4. 下位机使用兼容现有 `{#...}` 与 `$DST!` 协议的固件。
5. 气管、吸盘、棋子和取料区位置没有变化。
6. 第一次验证时不要直接运行完整流程，先逐项验证观察位和取料动作。

## 3. 启动软件

在项目目录打开 PowerShell：

```powershell
cd D:\Projects\Embodied\RobotArms\J1_Gomoku_Integrated
python -m app.main
```

也可以双击：

```text
scripts\run_gui.bat
```

看到窗口后先不要点击动作按钮。正常初始状态应为：

- Robot：`DISCONNECTED`
- Camera：`NOT READY`
- 标定发送状态：`SERIAL NOT CONNECTED / NOT SENT`

## 4. 界面分区

### 连接

- `连接摄像头`：打开真实摄像头。
- `断开摄像头`：停止相机采集。
- COM 下拉框：选择下位机端口，通常为 `COM6`。
- `连接 COMx`：以固定 `115200 baud` 连接下位机。
- `断开 COM`：停止串口通信；正在执行的未完成步骤会被取消。

### 三个任务页

1. `快速标定`：选择标定方案、调整 PWM、保存直接标定点。
2. `点位验证`：从 15×15 网格选择点位并实机验证。
3. `运行`：回观察位、取料、固定点演示和停止。

### 全局安全区

- `急停`：立即发送 `$DST!`、取消待执行动作并锁存 ESTOP。
- `气泵关闭`：发送气泵关闭命令。若正在吸取棋子，棋子会掉落，使用前必须确认下方安全。
- `急停后恢复`：只有 ESTOP 锁存后才启用；必须先完成下位机与现场安全复位。

### Advanced

只包含状态、视觉诊断和串口日志。日常取料与标定不需要展开。

## 5. 第一次连接与回观察位

1. 可选：点击 `连接摄像头`，确认画面方向正常。
2. 在 COM 下拉框选择正确端口。
3. 清空工作区并准备好物理断电。
4. 点击 `连接 COMx`。连接后机械臂软件状态先进入 `UNKNOWN`，此时不要取料。
5. 打开 `3 运行`，点击 `回观察位（取料区上方）`。
6. 等待动作完成，Robot 状态应变为 `OBSERVE_IDLE`。

观察位就是取料区上方的安全悬停位置。只有进入 `OBSERVE_IDLE` 后，取料按钮才会启用。

## 6. 取料操作

取料前确认：

- Robot 状态为 `OBSERVE_IDLE`；
- 棋子位于已标定的固定取料位置；
- 吸盘正下方没有手或其他物体；
- 气泵和气管连接正常。

然后在 `3 运行` 点击：

`取料：观察位 → 取料 → 观察位悬停`

软件依次执行：

1. `SOURCE_TOUCH_IDLE`：从观察位下降到取料位置，气泵关闭。
2. `SOURCE_TOUCH_HOLD`：在取料位置开启吸气。
3. 等待约 `700 ms`，建立真空。
4. `OBSERVE_HOLD`：保持吸气并回到观察区上方悬停。

动作完成后 Robot 状态应为 `OBSERVE_HOLD`，棋子保持吸取。此时不要点击“气泵关闭”，除非已经确认棋子可以安全落下。

如果取料按钮不可用，依次检查：COM 是否连接、机械臂是否忙、状态是否为 `OBSERVE_IDLE`、ESTOP 是否锁存。

## 7. 快速标定

> 新 Stage 7 标定动作尚未完成整板实机验证。第一次操作只使用 `Normal` 速度和 `Step 1`，每次只调整一个关节。

### 建立标定会话

1. 连接 COM，并先回到 `OBSERVE_IDLE`。
2. 打开 `1 快速标定`。
3. 点击 `载入稳定 Baseline`。
4. 选择方案：
   - `QUICK 5`：五个代表点，适合快速部署检查；
   - `STANDARD 9`：九个代表点，推荐用于正式部署标定。
5. 点击 `开始新标定`。

### 移动到当前 ABOVE 点

1. 核对“当前点”的点号、行列和 PWM。
2. 确保当前状态为 `OBSERVE_IDLE`。
3. 点击 `Move ABOVE`。
4. 等待动作结束，确认机械臂位于所选棋盘点上方且有足够净空。

每次切换到其他点前，应先到 `3 运行` 点击 `回观察位（取料区上方）`。软件会使用安全返回路径，不会从 ABOVE 点直接跳回观察位。

### 调整 PWM

- 仅 `J0–J4` 可以调整；`J5` 是气泵通道，已锁定。
- 建议首次使用 `Step 1` 和 `Normal=1000 ms`。
- `Slow`、`Fast` 尚未完成硬件调优，不建议首次实机标定使用。
- 在 PWM 输入框中键入数值只修改本地显示，不会立即发送。
- 按该行 `Apply` 或在输入框按 Enter，只发送对应的一个关节。
- `+` / `−` 会按当前 Step 调整并发送所选关节。
- `Apply All` 会一次发送 J0–J4 的当前值，不会改动气泵；只有确认单关节结果安全后才使用。
- 超出安全范围的值会被钳位，并显示 `OUT OF RANGE`。

### 保存与生成

1. 当前点位置确认正确后，点击 `Save Point · DIRECT`。
2. 点击 `Next` 前往下一个必需标定点。
3. 完成 QUICK 5 或 STANDARD 9 的直接点后，点击 `Generate / Recalculate 225`。
4. 系统会保留直接点，并为其他点生成 `AUTO (INTERPOLATED)` 候选值。

## 8. 点位验证与提交

网格颜色含义：

- `DIRECT`：人工保存的直接标定点；
- `AUTO / INTERPOLATED`：由直接点插值得到；
- `VERIFIED`：已成功实机移动并由操作者确认；
- `ERROR`：点位存在错误或验证失败。

验证步骤：

1. 打开 `2 点位验证`，选择一个点。
2. 确保机械臂已回 `OBSERVE_IDLE`。
3. 点击 `Move ABOVE`。
4. 实际观察位置、净空和机械臂姿态。
5. 正确时点击 `准确 · Verify`；不正确时点击 `不准确 · 重新标定`。
6. 验证下一个点前先安全返回观察位。
7. 完成必要验证后，在快速标定页点击 `Commit Calibration`。

提交只更新 Stage 7 部署文件，不会改写稳定 Stage 5 Baseline。`Rollback Baseline` 可把当前 Stage 7 部署恢复为稳定基线，同时保留会话历史。

## 9. 固定点演示

`开始固定点演示` 会连续执行取料并向固定 P77 放棋，属于高风险连续动作。只有同时满足以下条件才可使用：

- Robot 为 `OBSERVE_IDLE`；
- 摄像头已确认棋盘 `BOARD LOCKED`；
- P77 目标清晰可见；
- 取料、吸取、ABOVE 路径和 P77 放棋路径都已分别验证；
- 操作者全程守在物理断电位置。

第一次实机测试禁止从完整固定点演示开始。

## 10. 急停与恢复

### 出现异常运动

1. 立即点击红色 `急停`；若软件急停无效，立即物理断电。
2. 不要把手伸入仍可能运动或失压下坠的区域。
3. 检查障碍物、机械安装、吸盘和下位机状态。

### ESTOP 后恢复

1. 确认机械臂已经停止并得到可靠支撑。
2. 断开 COM，并按下位机要求复位或重新上电。
3. 清空工作区后重新连接 COM。
4. 点击 `急停后恢复` 并确认；软件状态回到 `UNKNOWN`。
5. 点击 `回观察位（取料区上方）`，重新建立 `OBSERVE_IDLE` 状态。
6. 不要直接继续刚才被中断的动作。

### 气泵关闭

`气泵关闭` 会取消未完成动作并关闭吸气，软件随后把机械臂姿态视为未知或错误。处理完棋子后，应重新回观察位，再开始新的动作。

## 11. 常见状态提示

| 提示 | 含义与处理 |
|---|---|
| `SERIAL NOT CONNECTED / NOT SENT` | 未连接 COM，没有发送。选择正确端口后显式连接。 |
| `NO SESSION / NOT SENT` | 尚未创建快速标定会话。先载入 Baseline 并开始新标定。 |
| `MOVE ABOVE FIRST / NOT SENT` | 当前机械臂不在所选点 ABOVE。先执行该点的 `Move ABOVE`。 |
| `ARM BUSY / NOT SENT` | 前一个动作未完成。等待完成，异常时使用急停。 |
| `ESTOP / NOT SENT` | 急停已锁存。按“ESTOP 后恢复”步骤处理。 |
| `OUT OF RANGE` | 输入超出关节安全范围，软件已经钳位；不要继续增大。 |
| `BOARD LOST` | 棋盘定位丢失。检查相机、光照、遮挡和 AprilTag 15–18。 |

## 12. 数据与日志

- 稳定动作表：`config/arm_actions.json`
- Stage 7 设置：`config/stage7_rapid_calibration.json`
- 稳定 Baseline：`calibration/stage5_board_calibration.json`
- 标定会话：`calibration/sessions/`
- 运行日志：`logs/session_YYYYMMDD_HHMMSS.log`

出现问题时保留当次日志，不要直接修改稳定动作表或 Baseline。

## 13. 建议的首次实机顺序

1. 空载、无棋盘：连接 COM，测试急停和复位流程。
2. 空载：回观察位，确认 `OBSERVE_IDLE`。
3. 放置单枚棋子：只执行一次取料，确认最后在观察位保持吸取。
4. 安全放下棋子并重新回观察位。
5. 只在一个已经验证的 ABOVE 点使用 `Step 1` 微调一个关节。
6. 完成单点安全返回后，再逐步扩大到 QUICK 5 / STANDARD 9。
7. 最后才测试固定 P77 完整演示。
